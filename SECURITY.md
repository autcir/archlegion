# Security Policy

## Reporting a Vulnerability

**Please do not open a public issue for security problems.**

Report via [GitHub Security Advisories](../../security/advisories/new) — the
Security tab of this repository → "Report a vulnerability".

Include what is affected, what an attacker could achieve, and how to reproduce
it if possible. Expect an initial response within 7 days.

## Supported Versions

The latest tagged release is supported. Older tags do not receive fixes.

## Secrets

This repository must never contain credentials. If you find a committed secret,
report it privately as above — do not open a public issue naming it.
